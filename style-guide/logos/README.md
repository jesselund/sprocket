# Logos

Extracted as clean vectors from the 2022 Sprocket brand guide (the supplied `.ai` file was damaged). The wordmark is drawn artwork based on Calibre Bold; never retype it.

- `sprocket-logo-color.svg`: primary lockup on light grounds. Coral symbol, midnight wordmark.
- `sprocket-logo-reversed.svg`: lockup on midnight, surface-inverse or photography. Coral symbol, white wordmark.
- `sprocket-logo.svg`: one-color lockup drawn in `currentColor`; set CSS `color` (ink, white or coral only).
- `sprocket-symbol-coral.svg`: the symbol alone in coral. Favicons, app icons, social avatars.
- `sprocket-symbol.svg`: one-color symbol in `currentColor`.

Clear space: at least the height of the symbol's single blade on every side. Minimum size: 96px wide for the lockup, 20px for the symbol.
